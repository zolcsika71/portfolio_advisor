# Portfolio Knowledge Sources

This directory contains portfolio-planning theory and methodology PDFs.

## Source groups

### Basic_Additional_info

Introductory portfolio theory, asset allocation, diversification and risk-return
concepts.

### Advanced_Additional_info

Advanced portfolio construction, optimization, risk measurement, statistical
methods and implementation techniques.

### PortfolioPython.pdf

Python-oriented portfolio analysis and implementation examples.

### AdvPortfolioPython.pdf

Advanced Python portfolio analytics, optimization and quantitative methods.

## Usage policy

- PDFs provide methodology and theory.
- Numerical portfolio observations come from SQLite.
- Graphify extracts concepts, relationships and source references.
- Graphify output is not automatically treated as an executable rule.
- Production rules must be reviewed and stored under
  `..ted_rules`.
